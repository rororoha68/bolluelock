# 캐릭터 플레이룸

스파인 캐릭터를 등록해두면 방문자가 갤러리에서 골라 인터랙션(톡톡 두드리기 / 볼 잡아당기기)과 모션 전환을 체험할 수 있는 정적 사이트예요. 방문자가 파일을 올리는 게 아니라, **로하가 파일을 미리 넣어두고 배포**하는 구조예요.

## 폴더 구조

```
spine-gallery-site/
├── index.html
├── README.md
└── characters/
    ├── manifest.json          ← 여기에 등록해야 갤러리에 보여요
    └── (캐릭터id)/
        ├── skeleton.json      (또는 skeleton.skel)
        ├── skeleton.atlas
        ├── skeleton.png       (아틀라스가 참조하는 이미지, 여러 장이면 전부)
        └── thumbnail.png      (선택, 갤러리 카드용 썸네일)
```

캐릭터 폴더 이름과 파일 이름은 자유롭게 지어도 되고, `manifest.json`에서 정확한 경로만 맞춰주면 돼요.

## 캐릭터 추가하는 법

1. `characters/` 아래에 캐릭터별 폴더를 새로 만들고, 스파인에서 내보낸 스켈레톤(.json 또는 .skel) + 아틀라스(.atlas) + 아틀라스가 참조하는 이미지들을 그대로 넣어요.
2. (선택) 96×96 정도의 정사각형 `thumbnail.png`를 같이 넣으면 갤러리 카드에 얼굴이 보여요. 없어도 이니셜 아이콘으로 대체돼요.
3. `characters/manifest.json`을 열고 아래 형식으로 한 줄 추가해요.

```json
[
  {
    "id": "yeonwoo",
    "name": "연우",
    "folder": "characters/yeonwoo",
    "skeletonFile": "skeleton.json",
    "atlasFile": "skeleton.atlas",
    "defaultAnimation": "idle",
    "thumbnail": "thumbnail.png",
    "description": "평소엔 새침하지만 볼을 당기면 당황해요."
  }
]
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | ✅ | 캐릭터를 구분하는 고유 값 (영문/숫자 권장) |
| `name` | ✅ | 갤러리에 표시될 이름 |
| `folder` | ✅ | 캐릭터 파일이 들어있는 폴더 경로 |
| `skeletonFile` | ✅ | `.json` 또는 `.skel` 파일명 |
| `atlasFile` | ✅ | `.atlas` 파일명 |
| `defaultAnimation` | 선택 | 처음 열었을 때 재생할 모션 이름. 없으면 첫 번째 모션이 자동 재생돼요 |
| `thumbnail` | 선택 | 갤러리 카드 썸네일 이미지 파일명 |
| `description` | 선택 | 오른쪽 패널에 보여줄 짧은 소개 문구 |

4. 저장 후 사이트 저장소에 커밋 → 푸시하면 Netlify가 자동으로 재배포해요. 로컬 서버를 따로 켤 필요 없이 바로 배포된 주소에서 확인하면 돼요.

## 인터랙션은 어떻게 인식되나요

- 본(bone) 이름에 `atama`가 들어가면 두 가지 제스처로 반응해요.
  - **짧게 클릭(터치)** → 콩콩 두드리기 반응. 애니메이션 이름에 `hit`, `smack`, `때리`, `두드`, `콩콩`이 들어간 모션을 찾아서 재생해요.
  - **드래그** → 쓰다듬기 반응. 애니메이션 이름에 `pet`, `stroke`, `rub`, `쓰다듬`, `쓰담`, `문지르`가 들어간 모션을 찾아서 재생해요.
  - 둘 다 해당하는 전용 모션이 없으면 즉석 스쿼시/흔들림 효과로 대신해요.
- 본 이름에 `cheek`, `볼`, `뺨`이 들어가면 드래그해서 잡아당길 수 있고, 손을 떼면 스프링처럼 튕겨 돌아와요. 이건 애니메이션 없이도 본을 직접 움직이는 방식이라 어떤 캐릭터든 바로 동작하고, 전용 모션을 만들어 등록하면 스프링 움직임 위에 추가로 재생돼요. (애니메이션 이름에 `pull`, `stretch`, `당기`, `늘리`가 들어가면 인식해요.)
- 둘 다 인식되는 본이 없으면 캐릭터의 가장 위쪽 본을 임시로 지정하고, 화면과 오른쪽 패널에 "(자동 추정)"이라고 표시해요. 본 이름을 저 패턴에 맞게 지어두면 더 정확하게 인식돼요.

### 전용 모션 + 후속 모션 만들기

두드리기/쓰다듬기/잡아당기기 각각에 대해, **전용 모션 하나만** 만들어도 되고 **전용 모션 + 후속 모션 두 개**를 만들어도 돼요.

- 전용 모션 하나만 있으면: 전용 모션 재생 → 원래 재생 중이던 모션으로 복귀
- 전용 모션 + 후속 모션이 있으면: 전용 모션 재생 → 후속 모션 재생 → 원래 재생 중이던 모션으로 복귀
- 두 모션은 모두 **반복 재생(loop) 없이 한 번만** 재생돼요.
- 후속 모션이라는 걸 알려주려면 이름 끝에 `after`, `end`, `out`, `2`, `후속`, `후` 중 하나를 붙여주세요. 예: `hit`(전용) + `hitAfter`(후속), `쓰다듬`(전용) + `쓰다듬후`(후속). 이 접미사가 없어도, 같은 키워드가 들어간 모션이 두 개 있으면 두 번째를 후속 모션으로 자동 인식해요.
- 전환 사이에는 0.25초 크로스페이드가 자동으로 걸려서 뚝 끊기지 않아요.

## 다국어(번역) 기능

사이트 메뉴/버튼/설명 같은 고정 UI 문구는 오른쪽 위 언어 선택 드롭다운(한국어/English/日本語/中文)으로 바로 전환돼요. 코드에 이미 4개 언어가 번역되어 있어서 별도 설정이 필요 없어요.

캐릭터 이름/설명, 스킨 이름/설명, 패치노트 내용처럼 **직접 입력하는 텍스트**는 자동 번역되지 않아요 (번역 API 없이 만든 사이트라서, 그리고 자동 번역은 보통 뉘앙스가 이상해져요). 대신 원하면 아래처럼 언어별로 직접 써서 등록할 수 있어요 — `manifest.json`/`site-config.json`에서 문자열 대신 언어 코드로 된 객체를 넣으면 돼요.

```json
{
  "name": { "ko": "치기리", "en": "Chigiri", "ja": "チギリ", "zh": "血吸" },
  "description": { "ko": "빨강이", "en": "The red one" }
}
```

언어별 번역을 안 채워둔 캐릭터는 그냥 하나의 문자열(`"name": "치기리"`)로 둬도 되고, 이 경우 모든 언어에서 같은 텍스트가 그대로 보여요. 현재 선택된 언어의 번역이 없으면 한국어 → (있는 아무 언어) 순으로 대신 보여줘요.

## 패치노트 / 제작자 표기 수정하는 법

`index.html`과 같은 위치(루트)에 있는 `site-config.json` 파일 하나로 둘 다 관리해요. 코드는 건드릴 필요 없이 이 파일만 고치고 재배포하면 돼요.

```json
{
  "creator": {
    "name": "로하",
    "url": "https://example.com"
  },
  "patchNotes": [
    {
      "version": "1.1",
      "date": "2026-09-08",
      "changes": [
        "볼 잡아당기기에 전용 모션 + 후속 모션 지원 추가"
      ]
    }
  ]
}
```

- `creator.name` / `creator.url` — 사이트 하단에 "제작: (이름)" 형태로 표시되고, `url`을 채우면 클릭 시 새 탭으로 열리는 링크가 돼요. `url`을 비워두면 링크 없이 이름만 표시돼요.
- `patchNotes` — 배열의 **맨 앞(0번)이 최신 버전**이에요. 새 패치노트를 추가할 땐 배열 맨 앞에 새 항목을 끼워 넣어주세요.
  - `version`: 버전 이름 (예: `"1.1"`, 화면엔 자동으로 `v1.1`처럼 표시돼요)
  - `date`: 날짜 문자열, 원하는 형식으로 자유롭게 (예: `"2026-09-08"`)
  - `changes`: 변경사항을 배열로 여러 줄 적을 수 있어요
- 상단 "패치노트" 버튼에는 새 버전이 추가되면 작은 점(●)이 떠요. 방문자가 한 번 열어보면 그 버전은 다시 안 떠요 (버전 이름이 바뀔 때만 다시 표시).

## 알아두면 좋은 점

- 완전히 클라이언트에서만 동작하는 정적 사이트라 별도 서버나 데이터베이스가 필요 없어요.
- 잡아당기기는 부모 본에 회전/스케일이 거의 없다는 가정의 근사치예요. 특정 캐릭터에서 방향이 어색하면 알려주면 보정 로직을 캐릭터별로 추가할 수 있어요.
- 스파인 러너타임은 `spine-webgl@4.1.*`을 쓰고 있어요. Spine 에디터에서 4.1.x 버전으로 내보낸 파일과 맞아요. 다른 메이저 버전으로 내보낸 파일은 러너타임 버전도 같이 맞춰야 해요.
